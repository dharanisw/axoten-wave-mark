# Current Process Description
## Teachers mark the essay questions manually:
* For the question make a model of a correct answer
* Read the each answer manually 
* Check each answer by comparing for model answer
* Mark the answer sheet

Need to repeat for each and every student so it is time consuming because need to read one by one if there is many student then it will be stressful and time consuming 

# Pain Points
* To mark the answer manually take too much time
* Score can be vary from teacher to teacher
* Difficult to give quick feedbacks
* Human can't work for a long time consistently and the results will not be same if we work without any break
* Hard to manage larger amount of answers
* Tracking the performance over the time will not be smooth

# User Persona
## Persona 1 : Teacher
* Age:25-60
* Role: Teach for the students and give assestments to improve them
* Goals:
    Reduce the time for marking the answers 
    Give the scores fairly not biased
    Provide feedback quickly
* Difficulties:
    Heavy workload during the exam periods
    Repititive tasks
    Delay due to the manual marking

## Persona 2 : Student 
* Age:16-18
* Role: Learn study and face for the Examinations
* Goals: 
    Receive marks faster
    Improve the marks by reveiewing where the marks have been lost
* Difficulties:
    Need to wait for long time to get the marks
    Stressful before the results release


## Persona 3 : Admin
* Role:Monitor the system activities and control the all users
* Goals:
    Ensure the marking system work smoothly
    Keep the records organized
* Difficulties:
    The creativity shouldn't ignored
    Need to handle larger datasets
    Need to be consistence and sholdn't take so much time
