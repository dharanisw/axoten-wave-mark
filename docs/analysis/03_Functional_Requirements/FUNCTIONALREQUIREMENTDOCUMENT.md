# Question Management
* Teacher can create, edit, and delete essay questions.

* Teacher can enter a module answer for each question.

* System must generate embeddings for each reference answer using Gemini API.

* Questions must be grouped under assessments or modules.

# Student Answer Submission
* Student can view assigned questions.

* Student can type and submit their essay.

* System must generate embeddings for each student answer.

* System must store each submission with timestamps and user details.

# Automatic Scoring
* System compares student embedding with reference embedding.

* System produces a similarity score.

* System converts similarity score into marks based on defined rules.

* System produces short feedback.

1.4 Results Display

* Student can view their marks and feedback.

* Teacher can view class results.

1.5 Admin Controls

* Admin manages user accounts.

* Admin reviews system health dashboards.
