# Version Control Rules (Docs)

* Each document must include version number

* Changes recorded in changelog

* Major edits require approval

* Naming: doc_v1.0, doc_v1.1, etc.

# Impact Analysis Steps

1. Identify affected modules

2. Check database field impact

3. Review UI screens

4. Check API updates

5. Update docs
