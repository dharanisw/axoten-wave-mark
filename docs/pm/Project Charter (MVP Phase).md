# Project Title: Wave Marker – MVP

Project Manager: Dharani Samudrika

Project Start Date: 26.12.2025
Expected End Date: 15.01.2026

## Purpose / Objective:
Develop an MVP of an automated essay grading system that allows teachers to upload marking schemes, students to upload essay answers (PDF/Image), leverages Gemini API for grading, and displays results to students.

## Scope:
### In-Scope:

* Uploading marking scheme by teachers

* Uploading answers by students

* Integration with Gemini API for grading

* Displaying grading results

### Out-of-Scope:

* Multi-language support

* Advanced analytics / dashboards

* Plagiarism checking

* Full user management & roles beyond teacher/student

### High-Level Deliverables:

1. Teacher interface for uploading marking schemes

2. Student interface for uploading answers (PDF/Image)

3. Backend integration with Gemini API for grading

4. Result display interface

### Key Stakeholders:

* Teachers (content creators)

* Students (content submitters)

* Project Manager / Team (developers)

### Constraints:

* MVP limited to PDF/image uploads

* Must use Gemini API

* Timeline limited to 26.12.2025 - 15.01.2026

### Assumptions:

* Teachers provide correct reference answers

* Student submissions are PDF or image only

* API is reliable during testing

### Risks:

* Gemini API downtime

* Upload format issues

* Incorrect scoring due to unusual answer formatting
